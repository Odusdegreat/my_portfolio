# Portfolio - Oluwatobi Odubote

A personal portfolio website showcasing projects, skills, and experience.

## Tech Stack

- **Framework**: React (Create React App)
- **Styling**: Tailwind CSS, daisyUI
- **Animations**: AOS (Animate on Scroll), Framer Motion
- **Email**: EmailJS (contact form)
- **Icons**: React Icons, Lordicon

## Features

- Responsive design
- Project showcase with modal details
- Skills categorization (Frontend, Mobile, Database, Backend, Web3, Tools)
- Contact form with EmailJS integration
- Admin dashboard for managing content

## Available Scripts

```bash
npm start       # Start dev server
npm run build   # Build for production
npm test        # Run tests
```

## Environment Variables

Create a `.env` file with:

```
REACT_APP_EMAILJS_SERVICE_ID=your_service_id
REACT_APP_EMAILJS_TEMPLATE_ID=your_template_id
REACT_APP_EMAILJS_PUBLIC_KEY=your_public_key
```
